# Green Careers · Designvorschau

Interaktiver Entwurf des Green-Careers-Karrierenetzwerks für Desktop und Mobile.

Der Einstieg öffnet **05 – Zusammen wachsen** für Arbeitgeber. Über die Navigation lassen sich die Arbeitnehmeransicht und vier weitere Designrichtungen vergleichen.

## Vorschau

- Responsive Ansichten für Arbeitnehmer und Arbeitgeber
- Jobsuche, Merkliste und fiktive Beispielstellen
- Original-Logo und Arbeitgeberlogos
- Animiertes Netzwerk und bedienbare Betriebsprofil-Vorschau
- Preisvergleich für Einmalpakete und Recruiting-Abo

Es handelt sich um einen Designprototyp. Anfragen und Bewerbungen werden nicht versendet. Die Paketauswahl öffnet nur eine Zusammenfassung; eine Buchung erfolgt ausschließlich auf der bestehenden Angebotsseite.

Alle Dateien werden statisch über GitHub Pages ausgeliefert. Schriften, Bilder und Logos liegen lokal; die Schriftlizenzen befinden sich im Assets-Ordner. Suchmaschinen sind durch robots.txt und noindex vom Indexieren ausgeschlossen bzw. zum Nicht-Indexieren aufgefordert.
